Manage articles

Sign in, import a TrendNova content-pack ZIP, upload cover images to Supabase, and publish articles. Articles are saved as drafts first so you can review them.

1. Connect Supabase

Enter your Supabase Project URL and publishable (or legacy anon) key. These browser-safe values are not admin secrets; access is protected by Supabase Auth and your database/storage policies. Never enter a service_role or secret key here.

This page keeps the connection details in this browser only. If you prefer, you can put the values directly in this file before committing it to your private workflow.

2. Admin sign-in

3. Import article ZIP

ZIP format: a manifest.json file with a non-empty posts array and an images/ folder. Supported categories are listed below.

Choose a content ZIP to begin.

Important

If connection or upload fails, do not disable Row Level Security. Check that the signed-in Auth user is registered in public.admin_users, that the table policies use public.is_trendnova_admin(), and that the article-images bucket exists with admin-only upload policies.
