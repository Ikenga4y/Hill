Content-pack format

If you ask ChatGPT to make a new batch, request a “TrendNova content-pack ZIP” containing manifest.json and image files. Example manifest:

{ "posts": [ { "id": "example-story", "title": "Article title", "category": "Technology & AI", "excerpt": "Short summary", "body": ["First paragraph.", "Second paragraph."], "image": "images/example-cover.jpg", "readTime": "4 min read" } ] }

Supported categories: Anime & Entertainment; Movies & Streaming; Technology & AI; Trending Stories; Downloads & Resources. Images can be JPG, PNG, WebP, or SVG.
